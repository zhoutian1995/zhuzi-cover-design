## 已观察到的视觉共性

| 维度 | 样本中看到的现象 | 对新封面的用法 |
|---|---|---|
| 背景 | 多数是暗窗帘、工作室、桌面或深色科技空间 | 保留场景光和空间纵深，避免空黑底 |
| 人物 | 同一创作者反复出现，常在中右、右下，手势参与表达 | 换成用户本人，按主题变化身体姿态与目光；默认不摆展示手势 |
| 文字 | 极粗、偏窄、常带倾斜与黑色描边，白字与亮色重点并置 | 先决定最大钩子词，再排说明文字 |
| 排版 | 有上置标题，也有中置、下置标题；常避开面部 | 按人脸和主道具分配空白，不固定底部条 |
| 冷色 | 蓝、青、紫集中在工具、屏幕、连接线和轮廓 | 用于工具组合、工作流和自动化过程 |
| 暖色 | 黄、金、橙、红用于结果、利益与冲突 | 亮色突出结果或问题，背景保留深色层次 |
| 证据道具 | 软件卡片、电脑、流程节点、设备、胶片、书稿等 | 道具必须能说明这条视频的内容 |
| 空间 | UI 卡片倾斜、前景物件较大、少量光效 | 形成“前景道具—人物—背景”的层次 |
| 小文字 | 一些封面顶部有小英文眉题 | 可选装饰，缩小时不影响主要信息 |

人物和道具并非两张图片并排摆放。常见结构是一个主体道具占一侧，人物在另一侧，通过手势、目光、透视或光线连起来。

## 不应误当作统一规则的例外

- 样本 3 是个人目标旗帜，人物近景与橙色文字为主，不是科技 UI 拼贴。
- 样本 9 是大会现场分享，采用明亮户外现场和黄色重点。
- 样本 16 是浅色产品结果封面，白色背景、产品主视觉和橙色结论。

用户内容属于生活记录、线下活动或产品展示时可参考这些例外。不要为追求“像”而强行添加科技蓝光。

## 设计建议与证据的界线

下面是为了复用而提出的设计起点，不是从原图提取的参数：

- 画布建议：3:4，1080×1440。
- 背景近似色：#10131B、#09162A；冷色重点 #58C7FF、#846BFF；暖色重点 #FFD34E、#FF853B、#F24646。
- 字体建议：重黑体、窄体或略微倾斜；没有验证作者具体字体。
- 人物约占画面宽 35%～50%，主标题覆盖约 20%～35% 的面积，按照片调整。
- UI 卡片先用 2～4 张，主道具一个；这是防止新图失焦的控制建议，不是原作者的固定计数。
- 内容可信度、标题可读性、人物辨认度优先于装饰密度。

没有后台点击率、完播率、原始设计稿或作者制作流程。不要用页面点赞数字论证某种封面布局必然带来增长。
