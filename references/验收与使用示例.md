# 验收与使用示例

## 交付检查

| 检查 | 通过标准 |
|---|---|
| 标题 | 标题逐字正确，字号足够大，手机网格中可读 |
| 旧字清除 | 原壁纸旧标题、Logo、装饰线和残影完全消失 |
| 右侧人物 | 脸、头发、衣服、姿势、身体和背景没有被标题覆盖或重新生成 |
| 视觉冲击 | 蓝白标题、粗描边、阴影和留白形成明确视觉重点；不堆无关装饰 |
| 品牌字 | 默认不添加固定品牌字；用户本条明确要求时才检查品牌文字 |
| 构图 | 标题只在左侧安全区，右侧主体完整可见 |
| 文字白名单 | 只有本条标题和用户明确指定文字，没有平台数据、Logo或装饰英文 |
| 画幅 | 3:4、9:16、16:9按实际要求制作；回读真实尺寸，不把设计目标当成成品尺寸 |
| 输出 | 明确区分提示词、生成预览和实际成品 |

## 示例 1：固定壁纸替换标题

用户提供一张桌面壁纸，并说：

> 去掉左边原来的字，标题换成“FDE是外交 / 还是外包”，右边的人不要动，蓝色要有冲击力，不要署名。

合适的交付：

- 原图右侧人物和背景保持不变；
- 左侧原文字和装饰线完全清除；
- 左侧使用大字号蓝白标题和深色粗描边；
- 不添加小天说FDE或其他品牌字；
- 检查标题没有盖到人物。

## 示例 2：只要提示词

用户说：

> 使用我的壁纸，只给提示词，标题是“AI写代码，谁来验收？”

交付完整编辑提示词，写清固定壁纸、旧字清除、左标题、右侧人物保护和不添加品牌字，不报告已生成图片。

## 示例 3：用户本条要求品牌

用户说：

> 标题下面加我的品牌“小天说FDE”。

只在本条加入指定品牌，逐字核对位置和清晰度；不把这次品牌要求扩展为所有未来封面的默认规则。

## 公开版边界

公开仓库只包含通用规则和提示词，不包含用户私人壁纸、照片、脸模、知识库路径或账号凭据。静态检查不等于图像生成成功，也不等于平台上传或点击效果验证。
