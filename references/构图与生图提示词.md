# 构图与生图提示词

## 固定壁纸编辑原则

这是对现有壁纸的局部编辑，不是重新生成整张图：

1. 清除左侧原有标题、Logo、装饰线和残影；
2. 左侧大留白放本条视频标题；
3. 右侧人物、脸、衣服、姿势、桌面、书架、窗光和背景保持不动；
4. 默认不添加品牌字；
5. 标题使用蓝色、白色和深色粗描边时，参考用户提供的视觉参考图；
6. 标题不得进入右侧人物脸部和身体区域。

## 三种画幅起点

- **3:4**：以固定底图为编辑源，左侧标题块按画幅缩放，右侧人物保持完整。
- **9:16**：优先保留左标题和右侧人物的关系，不把标题压到人物上。
- **16:9**：保持原壁纸横向构图，只调整标题字号和安全边距。

## 参考图角色

| 输入 | 作用 |
|---|---|
| 固定壁纸 | 背景、人物、光线、桌面和版式；编辑时优先保持原图 |
| 标题参考图 | 只参考字体重量、颜色、描边和视觉冲击，不复制人物或Logo |
| 用户本人照片 | 只有用户明确要求替换固定壁纸人物时才使用 |
| 内容素材 | 真实软件、设备、产品或成品；没有素材时不伪造证据 |

## 可直接填写的提示词

```text
这是对一张现有桌面壁纸的局部编辑，不是重新生成整张图。
固定底图：{用户提供的壁纸文件}。
完全保留右侧人物的脸、头发、衣服、姿势、身体、桌面、书架、窗光和全部背景关系；不换脸、不重画人物、不改变人物位置。
完全清除左侧原有的旧标题、Logo、装饰线和任何文字残影。
在左侧大留白中加入本条视频标题：
第一行「{第一行标题}」
第二行「{第二行标题}」
{第三行标题可选}
标题使用大字号、高冲击蓝白配色，白色或蓝色粗描边，深色阴影，参考图的字效但不复制第三方人物和Logo。
标题只占左侧安全区域，不盖住右侧人物的脸、身体和主要背景。
默认不添加小天说FDE或其他固定品牌字。
除标题外不添加平台数据、点赞数、认证、装饰英文、Logo或无关文案。
```

## 跨画幅适配提示词

```text
从同一固定壁纸模板制作{目标画幅}封面。
保留右侧人物与背景，不重新生成右侧区域；只调整左侧标题的大小、分行和安全边距。
标题逐字保留「{原标题}」，旧标题必须完全消失，不留残影。
默认不加品牌字，不加平台UI，不加无关装饰。
回读实际像素和比例，检查标题可读、人物未被覆盖。
```

## 生成后检查

- 旧标题是否完全消失；
- 新标题是否逐字正确；
- 标题是否足够大且不越界；
- 右侧人物是否没有被覆盖或重画；
- 是否误加了品牌字、平台数据或Logo；
- 实际像素和宽高比是否已回读。
