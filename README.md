# 固定壁纸模板短视频封面 Skill

由 **小天说FDE** 整理。这个公开版不是重新生成一张相似风格的人像，而是把用户提供的桌面壁纸或版面图当作固定底图：

- 清除原图已有的标题、Logo或旧字；
- 在左侧留白中放本条视频的大标题；
- 保留右侧人物、背景、桌面、书架和光线；
- 默认不自动添加品牌字；
- 同一底图可适配3:4、9:16和16:9。

## 安装

```bash
git clone https://github.com/zhoutian1995/zhuzi-cover-design.git ~/.codex/skills/zhuzi-cover-design
```

已有同名 Skill 时先保留本地修改，不直接覆盖。其他宿主按各自的 Skill 安装方式加载整个仓库目录。

## 使用示例

```text
使用 $zhuzi-cover-design，在我提供的桌面壁纸上制作短视频封面。
清除原来的标题，只在左侧写：FDE是外交 / 还是外包。
保留右侧人物和背景，不加品牌字，使用蓝白高冲击标题。
```

只要提示词时：

```text
使用 $zhuzi-cover-design，只给我固定壁纸模板的封面提示词，不生图。
标题：FDE是外交还是外包。左侧大字，右侧人物不动，不加署名。
```

## 能做什么

- 固定壁纸局部编辑；
- 左侧标题替换与高冲击字效；
- 保留人物身份和背景；
- 处理旧字清除、白名单文字、跨画幅裁切；
- 输出提示词或实际图片。

Skill 本身不提供图像模型、API Key或自动发布能力。公开仓库不包含作者照片、脸模、私人壁纸或知识库路径。

## 边界

新图使用用户自己的壁纸、身份、品牌、选题和有权使用的素材；不复制第三方人物、Logo、平台数据或原封面。公开仓库不等于附带第三方图片或品牌授权。
