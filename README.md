# 电影感科技短视频封面 Skill

由 **小天说FDE** 整理。把选题或口播稿做成真人、粗重标题、主道具与暗场景组成的科技封面，默认交付 3:4、9:16、16:9 三种画幅。

公开版包含完整的制作规则、中文生图模板和验收方法。使用者提供自己的照片、选题和品牌；仓库不包含作者的照片、脸模、私人知识库、参考创作者的截图或账号凭据。

## 能做什么

- 根据正文提炼结果、冲突或疑问标题；用户指定标题时只调整分行。
- 按主题选择蓝紫工作流、金色结果、红橙冲突或大字判断构图。
- 区分人像基线、身份照片与待改版面，保留自然精修与头颈肩身体关系。
- 同题跨画幅保持人物、动作、眼神、衣服、主道具与主题连续。
- 使用文字白名单，检查中文、杂字、裁切、实际像素与素材真实性。

## 安装与使用

将整个仓库作为一个名为 `zhuzi-cover-design` 的 Skill 文件夹放入支持 `SKILL.md` 的工具发现目录。以 Codex 常用用户目录为例，目标目录尚不存在时可执行：

```bash
git clone https://github.com/zhoutian1995/zhuzi-cover-design.git ~/.codex/skills/zhuzi-cover-design
```

已有同名 Skill 时先保留原有修改，不直接覆盖。其它 Agent 工具按各自的 Skill 安装方式添加整个文件夹。

然后在能加载该 Skill 的会话里提供本人参考图并请求：

```text
使用 $zhuzi-cover-design，给“FDE近期线下分享合集”做短视频封面。
使用我提供的照片，署名“我的账号名”，不要摆展示手势。
同步3:4主版、快手9:16和16:9横版。
```

只需要提示词时可以说：

```text
使用 $zhuzi-cover-design，只给我封面提示词，不生图。
选题：用AI整理口播稿。署名：我的账号名。画幅：3:4。
```

Skill 本身不提供图像模型、API Key 或自动发布能力。有图像工具的宿主可实际生图；没有图像工具时交付完整提示词，并说明尚未生成图片。

## 画幅约定

| 用途 | 比例 | 设计目标 |
|---|---|---|
| 抖音／小红书主版 | 3:4 | 1080×1440 |
| 快手长竖版 | 9:16 | 1080×1920 |
| 同步横版 | 16:9 | 1920×1080 |

这是本工作流的设计偏好，不代表所有平台发布入口都要求这些尺寸。图像工具可能输出其它原生像素，交付时须读取实际尺寸，不能把目标尺寸写成已完成尺寸。
